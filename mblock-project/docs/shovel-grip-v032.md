# v032 握紧铁铲

项目：`exports/沙漠绿色公益-握紧铁铲-v032.mblock`。

原先整把铁铲在机器人后方，柄被身体和腿挡住，看起来像铲头悬空。现在将铁铲放到机器人前一层，在握点留出透明遮挡区，让原始蓝色手指覆盖柄，同时让柄在身体和腿前方连续可见。站姿、挥手、旧种植姿势和 24 帧种植动作逐一校准握点，保留原有加长铲子的长度和角度变化。

机器人原始像素不变；SVG 使用原生 mask，握点对应旋转中心 (50, 280)。逐帧位置继续跟随机器人造型。
