# v033 每关不同音乐

项目：`exports/沙漠绿色公益-每关不同音乐-v033.mblock`。

十关分别使用十段原创合成器乐循环，旋律、节奏、调性及音色不同，没有下载录音或使用第三方音乐采样。

每段为 4 小节、约 8.6～12.6 秒的循环，使用单声道 16-bit PCM WAV，采样率 16 kHz。两端淡入淡出，峰值约 0.72，无削波。项目大小约 39.36 MiB，保持在 MCP 导出上限 40 MiB 内。

舞台从“关卡音乐名称”列表按当前关卡选曲。开始关卡先停止旧声音，再以 30% 音量循环；答错重来播放当前关卡的音乐；五株植物全部长大后停止，烟花和徽章期间不继续播放背景音乐。M 键仍可切换静音。答对与通关提示音保留。

node scripts/add-level-music.mjs
