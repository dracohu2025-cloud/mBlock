# v043 种植后原地等待

项目：`exports/沙漠绿色公益-原地等待-v043.mblock`。

机器人每种完一株植物，就恢复待机姿势并留在当前种植点回答下一题；下一次答对时，直接从当前位置走到下一个种植点。移除旧的自动返回答题起点的回程。

保留等待种植动画完成的条件，再显示下一题，避免种植与答题重叠。新关卡、答错重试和重新挑战仍按原有逻辑回到关卡起点。A/B 选项按钮、机器人无铲 PNG、植物成长、沙生绿洲、音乐、烟花和徽章不变。

```sh
node scripts/stay-after-planting.mjs
node scripts/verify-levels.mjs mblock-project/exports/沙漠绿色公益-原地等待-v043.mblock
node scripts/verify-option-buttons.mjs mblock-project/exports/沙漠绿色公益-原地等待-v043.mblock
```

十关流程模拟包含 70 段前进行走，没有回程；后续行走均从上一次种植点出发。50 次正式答题检查机器人站在起点或上一株植物的位置，种植完成后保持待机，等待答题期间位置不变。失败重试、重玩、132 道题与按钮对应关系及全部奖励流程检查通过。

已在本机 mBlock 点选验证：答对第一题后种下一株，第二题显示时机器人仍留在该种植点，没有返回起点。随后通过编辑界面的「保存」操作保存新版文件。
