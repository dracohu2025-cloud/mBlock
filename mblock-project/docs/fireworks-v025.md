# v025 通关烟花

舞台在等待“已长大树数 = 5”之后判断是否为最后一关；满足条件时将“关卡状态”设为 3，广播“通关烟花”，等待“烟花播放完毕 = 1”，再进入原有的状态 2。继续按钮在状态 3 下保持隐藏且拒绝点击。
