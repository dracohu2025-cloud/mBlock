# v039 完整走路造型与移除铁铲

项目：`exports/沙漠绿色公益-无铲走路-v039.mblock`。

现场操作 mBlock 5.6.0 发现，v037 的 SVG 走路造型在原生应用中被裁切，部分身体消失；SVG 中的铁铲也未完整显示。此前使用独立 SVG 渲染器的素材预览没有复现该问题。原生录屏确认了问题，而不能仅凭离线素材检查认定应用兼容。

修正方式：将机器人全部 37 个造型导出为完整透明 PNG，使用双倍分辨率及对应的双倍旋转中心，保持原来的舞台尺寸和定位，避免运行时解析嵌套 SVG、use 和 clipPath。保留八帧走路与原有 24 帧种植动作。

按用户后续要求，从每个造型中移除铁铲图形，并删除独立的 `机器人铁铲` 角色。走路、种植及答题逻辑不变。最终项目约 32.4 MiB，低于 MCP 的 40 MiB 导出上限。

生成与检查：

```sh
node scripts/native-robot-costumes.mjs
node scripts/verify-native-robot.mjs
node scripts/verify-levels.mjs mblock-project/exports/沙漠绿色公益-无铲走路-v039.mblock
```

`assets/props/native-v039/costumes.json` 记录源造型、原始旋转中心、PNG 资源及游戏代码摘要，避免独立旧文件在应用中另存、试玩后产生的运行状态差异影响代码比较。检查所有造型的完整轮廓、透明边界、缩放与旋转中心、素材及积木引用。十关流程模拟包含 130 段往返路径、失败重试、植物成长、音乐、烟花、徽章和重玩。

本次已在真实 mBlock 中打开并演示无铲版本的答题、走路、种植和返回。原生录屏确认机器人完整显示，未出现 v037 的裁切问题。`assets/props/native-v039/demo-mblock.mp4` 是实际应用录屏的 8 秒节选，`demo-walking.png` 是其中的走路画面。实际演示只覆盖了部分第一关，十关完整流程使用脚本模拟验证，没有声称完成原生应用十关试玩。

已在 mBlock 编辑界面点击顶部“保存”，并确认 v039 文件的修改时间与大小更新；保存后的文件再次通过素材和流程检查。本次使用 macOS 原生界面操作，MCP Bridge 未连接，没有通过 MCP 控制来演示。
