# v021 答错从本关第 1 题重来

项目：`exports/沙漠绿色公益-答错重来-v021.mblock`

- 任意一题答错后立即锁定 A/B 输入，显示“答错了！本关从第1题重新开始。”
- 清空本关已种树、已落苗、种植完成和长大计数，隐藏上一轮树木，并重新开始本关。
- 当前关卡不变，已通过的关卡保留；重新随机抽题，题号从第 1/5 题开始。
- 连续答对 5 题后仍执行原有树木长大、停止音乐和下一关流程。

## 实现

`scripts/restart-on-wrong-answer.mjs` 基于本地 v020 添加独立的“重试本关”广播处理。答错的机器人脚本广播后结束当前脚本，避免误入答对种树分支；关卡管理脚本继续等待本关完成。
