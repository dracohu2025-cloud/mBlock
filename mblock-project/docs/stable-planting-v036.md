# v036 种植动画稳定性

项目文件：`exports/沙漠绿色公益-种植稳固-v036.mblock`。

v035 的种植帧按天线水平位置对齐，但脚底仍有横向位移；旧站立造型切入种植帧时，脚底中心还会跳动约 12 个舞台像素。铁铲通过独立角色的循环读取机器人状态，两者也可能在不同刷新时刻显示不同姿势。

v036 做了三项修正：

- 改用双脚鞋底的中心和落地高度对齐。全部 24 帧保持同一个脚底落点，弯腰动作保留。
- 种植前后都使用动画的第一个直立姿势待机，避免不同来源的站立画面在切入、切出时跳变。
- 每个造型以 SVG 同时放置原始机器人 PNG 和对应的铁铲矢量形状。机器人 PNG 字节不变；此前修正的手掌遮挡、铲面朝向和长度保留。铁铲原角色与素材仍保留，单独显示及跟随循环关闭，消除身体与铲子的跨角色刷新差。

造型名称、24 帧顺序和原有 `1/24` 秒等待值保持不变；题目、关卡、植物、背景、音乐、烟花、徽章及答题逻辑未修改。原始 PNG 以无损方式嵌入 SVG 后，删除 ZIP 内不再被引用的重复 PNG 文件，完整项目仍小于 MCP 导出上限 40 MiB。

生成与验证：

```sh
node scripts/stabilize-planting.mjs
node scripts/verify-stable-planting.mjs
node scripts/verify-levels.mjs mblock-project/exports/沙漠绿色公益-种植稳固-v036.mblock
node scripts/preview-stable-planting.mjs
```

逐帧检测：鞋底中心及落地高度偏移均小于 0.5 个舞台像素；11 个独立 SVG 可正常渲染，边界透明；机器人原始 PNG、铁铲形状与掌部遮挡逐一核对；素材和积木引用完整。十关流程脚本模拟通过，包括失败重试、成长、音乐音量与停止、烟花、徽章和重玩。

`assets/props/stable-v036/alignment.json` 保存原造型信息及逐帧对齐、握点记录；`preview.png` 为姿势对照，`planting-preview.mp4` 是按项目素材和坐标渲染的 24 fps、3 秒连续预览，包含两次种植及前后待机。
