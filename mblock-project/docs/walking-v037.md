# v037 机器人走路

项目：`exports/沙漠绿色公益-机器人走路-v037.mblock`。

新增 `走路-01` 至 `走路-08`，机器人共有 37 个造型。走路姿势使用现有 SVG 造型中的机器人图像作腿部分层与关节变换，保持上半身、手掌和铁铲一起显示。步态包含左右腿交替抬起、前摆和落下。走路造型专用嵌入图片按舞台显示尺寸优化；原有 29 个造型及其定位参数保持不变。

答对题目后，机器人按 24 个小步插值移动到种植点，同时循环三次八帧步态，每步沿用 `1/24` 秒等待值。到达后恢复种植待机造型，再触发种植计数。下一题显示前，先等待种植完成数等于已种树数，再播放返回答题位置的走路动画。第一题已在答题位置时跳过返回；关卡初始化仍直接设置起始位置。

连续预览：`assets/props/walk-v037/walking-preview.mp4`，24 fps、96 帧、4 秒，演示去程、种植和回程。该视频是素材与坐标渲染的预览，不是 mBlock 应用录屏，也不证明应用内实际帧率。八个姿势对照见同目录 `preview.png`。

生成和验证：

```sh
node scripts/add-robot-walking.mjs
node scripts/verify-shovel-grip.mjs mblock-project/exports/沙漠绿色公益-机器人走路-v037.mblock
node scripts/verify-levels.mjs mblock-project/exports/沙漠绿色公益-机器人走路-v037.mblock
node scripts/preview-robot-walking.mjs
```

验证结果：

- 八个走路造型实际渲染后，腿部姿势变化，上半身与握铲区域一致，边界透明；原有种植动画脚底对齐检查通过。
- 十关模拟完成 130 段去程和回程，每段包含 24 个连续位置更新，步态按八帧循环，准确到达目标；回程均在种植完成后开始。
- 失败重试、题目唯一性、成长、音乐、烟花、徽章和重玩通过原有流程模拟；非机器人目标对比直接基线 v036 保持一致。
- 素材、积木引用完整；项目小于 MCP 导出上限 40 MiB。
